# A Neuro-Symbolic AI Scientist for Equation Discovery

modular neuro-symbolic framework for automated scientific equation discovery that integrates Graph Transformers, EGNNs, GATs, FNOs, DeepONets, causal discovery, LLM-guided symbolic regression, and physics-aware verification to uncover interpretable scientific laws from data.

---

## 🚧 Project Status

This project is currently under active development.

The repository serves as the implementation space for an ongoing research project focused on combining deep learning, symbolic reasoning, causal inference, and scientific knowledge to discover interpretable mathematical equations directly from data.

---

## 🎯 Research Objective

The primary objective of this project is to build an AI system capable of moving beyond prediction and toward scientific discovery by automatically identifying the underlying laws governing complex systems.
